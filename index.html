iPhone公開中個人制作

ねこの暮らし手帳

毎日のお世話、健康、通院、遊び、予定を猫ごとにまとめて残せる、ローカルファーストの記録アプリです。二匹と暮らす中で、記録したい内容が複数の場所に分かれてしまう不便をなくすためにつくりました。

できること

  • お世話・体重・食事・水分・投薬・通院を猫ごとに記録
  • カレンダーとグラフで日々の変化を振り返る
  • ホーム画面ウィジェットからお世話や遊びを操作
  • 期間を指定した診察用まとめをPDFで保存
  • 写真を含むバックアップを暗号化して保存・復元

技術構成

React 19TypeScriptViteCapacitor 8SQLiteSwiftUIWidgetKitVitest

実装・設計のポイント

  • ローカルファースト — 構造化データは正規化したSQLite、写真はアプリ専用領域に保存。アカウントや外部サーバーを必要としない構成。
  • WebとiOSの連携 — React／TypeScriptのUIをCapacitorでiOS化し、通知・生体認証・ファイル共有などの端末機能と接続。
  • ウィジェット連携 — SwiftUI／WidgetKitとApp Groupを使用。ウィジェット操作を一時保存し、アプリ起動時に正式な履歴としてSQLiteへ反映。
  • データ保護 — 写真を含むバックアップ、AES-256-GCM暗号化、スキーマ更新と復元時のトランザクション処理に対応。
  • 記録の整合性 — お世話の取り消しや在庫の増減で数字がずれないよう、ロジックを分離して自動テストで確認。

iPhone公開中個人制作

Reward Calendar

毎日の小さな目標をスタンプで記録し、達成をポイントと自分へのご褒美につなげる習慣化アプリです。記録を義務にせず、操作した瞬間に楽しい反応が返ることを意識してつくりました。

できること

  • 自由に目標を作成し、今日または過去の日付へ達成スタンプ
  • 連続達成日数、月間達成率、過去6か月の推移を確認
  • ポイントを自分で決めたご褒美、スタンプ、テーマと交換
  • 写真と一言をフォトログに残し、リマインド通知を設定
  • 目標・達成記録・写真・設定をまとめてバックアップ・復元

技術構成

SwiftSwiftUISQLite3UIKitUserNotificationsCanvasXCTestiOS 17+

実装・設計のポイント

  • ネイティブ構成 — SwiftUIを中心に、カメラ・触覚フィードバック・通知などはUIKitやiOSの標準APIと連携。
  • ポイントの整合性 — 達成、交換、スタンプ購入をSQLiteのポイント台帳とトランザクションで管理。使いすぎや二重購入を防止。
  • 達成時の体験 — スタンプのスプリングアニメーションに加え、CanvasとTimelineViewで紙吹雪・花火を描画し、触覚フィードバックも連動。
  • 写真の扱い — オリジナルとサムネイルを分けて端末内に保存し、一覧表示では画像をダウンサンプリングして読み込み。
  • 安全な復元 — SQLiteの整合性とファイル名を検証してから復元し、失敗時は復元前のデータへ戻す設計。

iPhone公開中個人制作

Naile

色やパーツを選び、ネイルデザインを画面上で組み立てて確認できるアプリです。Web版の試作を経て、iPhoneアプリとして公開しました。

できること

  • プリセットまたはカスタムカラーからベース色を選択
  • 五本表示と一本表示を切り替え、爪ごとにデザイン
  • パーツの配置、質感、色、サイズ、立体感を調整
  • カメラ撮影または写真を読み込み、デザインを確認
